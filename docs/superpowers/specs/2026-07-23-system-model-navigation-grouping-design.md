# 系统模型菜单分组设计

## 目标

调整系统管理左侧导航的信息架构，使模型相关能力集中在“模型管理”分组下，同时保持现有路由、页面、权限和接口不变。

## 菜单结构

- 常规入口：概览、用户管理、工作空间管理。
- 模型管理：模型配置、模型定价、模型监控。
- 独立入口：沙箱管理。
- 订阅与积分：积分基础配置、订阅套餐、积分包、用户积分、积分记录、订单管理。
- 独立入口：系统配置。

“模型定价”沿用现有名称，不改为“模型底价”。`/system/billing-pricing` 与 `/system/billing-monitoring` 路由保持兼容，只调整导航归属。

## 实现方式

在 `content.ts` 中增加显式导航分组配置，以分组配置作为唯一的菜单排序来源；`index.tsx` 根据分组配置渲染标题和子项。无标题分组继续使用原一级菜单样式，有标题分组使用现有 `is-child` 样式。

## 验收

- 模型管理依次显示模型配置、模型定价、模型监控。
- 订阅与积分不再显示模型定价、模型监控。
- 所有系统管理入口只出现一次。
- 现有 URL、页面加载和管理员权限行为不变。
