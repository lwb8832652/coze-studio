# 工作流大模型提示词必填校验设计

## 背景

工作流大模型节点允许用户提示词为空。执行时后端会补一条空用户消息并继续请求
模型，导致模型在没有有效输入的情况下返回无关内容。

## 目标

- 系统提示词和用户提示词至少填写一个，两者都不单独强制必填。
- 提示词可以是固定文本，也可以引用变量；变量引用不是必填条件。
- 空白字符串不能通过校验。
- 前端提供现有表单体系的标准必填标记和错误反馈。
- 后端拒绝没有任何有效提示词的请求，避免绕过前端后继续调用模型。

## 方案

前端为系统提示词和用户提示词增加组合校验。两个字段都为空或仅包含空白字符时
校验失败；任一字段存在有效内容即可通过。校验不检查是否包含变量。节点试运行
和整条工作流试运行继续复用现有节点校验流程。

后端在构建大模型节点提示词时执行相同的组合校验。系统提示词和用户提示词都缺失
或仅包含空白字符时返回明确错误，不再构造空用户消息，也不调用模型服务。只配置
系统提示词时保留兼容所需的空用户消息，但该请求已经包含有效系统指令。

## 错误处理

前端使用现有标准提示说明两个提示词至少填写一个，不增加变量使用说明。后端错误
信息表达相同约束，供 API 调用和异常草稿兜底。

## 验证

- 前端测试覆盖两个字段均为空、纯空白、仅系统提示词、仅用户提示词、固定文本和
  变量模板。
- 后端测试覆盖两个提示词均为空时被拒绝，以及仅配置任一提示词时正常生成消息。
- 页面回归确认必填标记、错误反馈和正常试运行行为。
