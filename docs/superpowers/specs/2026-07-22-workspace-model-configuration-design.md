# 工作空间模型配置设计

## 目标

在现有账号设置弹窗中新增 `模型配置`，按 Nuwax 的模型范围设计提供两类模型：

- `系统模型`：由系统管理员维护，当前用户只读查看可用模型。
- `工作空间模型`：归属当前工作空间，空间 Owner/Admin 可管理，普通成员只读。

该功能不是用户私有 BYOK。模型配置随当前工作空间切换，个人空间也按一个工作空间处理。

## 参考证据

Nuwax 的模型合同包含 `Global / Tenant / Space` 三种范围，模型记录包含
`creatorId` 和 `spaceId`。前端通过 `System / Space` 两个视图展示当前用户可用
模型，并为工作空间模型提供新增、编辑、删除和连通性测试。

Coze 侧继续使用现有 `modelmgr` 作为模型执行和元数据主实现，不复制 Nuwax 的
Java 数据层。工作空间授权通过 Coze 自身的空间身份和模型授权关系表达。

## 产品设计

### 入口与信息架构

`设置` 左侧菜单顺序调整为：

1. 账号
2. API 授权
3. 模型配置
4. MCP 配置
5. IM 机器人

`模型配置` 内容区顶部使用两个页签：

- `系统模型`：展示管理员开放且当前工作空间可用的模型。
- `工作空间模型`：展示当前空间创建的模型。

页签、工具栏、卡片、表单、空态、错误态沿用当前设置弹窗和 NewX 绿色视觉体系，
不新增一级菜单或独立路由。

### 系统模型

- 支持按供应商、模型名称和模型标识搜索。
- 展示供应商、模型名称、模型标识、能力、状态和可用场景。
- 不显示 API Key、内部 endpoint、密文、审计载荷或 Provider 原始响应。
- 所有用户只读，修改入口仍在 `/system/models`。

### 工作空间模型

- Owner/Admin 可新增、编辑、启停、删除和测试连通性。
- 普通成员可以查看模型元数据和可用状态，不能查看或修改凭证。
- 新增和编辑字段对齐 Nuwax 的有效合同：供应商、显示名称、模型标识、协议、
  Base URL、API Key、模型能力、函数调用能力、最大输出 Token、上下文长度、
  启用状态和使用场景。
- API Key 为只写字段。编辑时仅展示“已配置/未配置”，留空表示保留原凭证。
- 删除前返回依赖摘要；存在运行中任务或受保护依赖时拒绝删除并给出明确原因。
- 连通性测试使用尚未保存的表单值，服务端执行限时、脱敏的最小请求。

## 权限与数据边界

- `space_id` 和操作者身份只从服务端认证上下文及空间成员关系推导，不信任前端。
- 系统模型由系统管理员管理，工作空间模型由空间 Owner/Admin 管理。
- 工作空间模型必须绑定唯一空间授权，查询时按当前用户可访问空间过滤。
- API Key 使用现有模型凭证 codec 加密保存，不明文落库、回显或写日志。
- 列表和详情只返回凭证状态，任何导出能力都不能包含凭证。
- 普通成员对写接口返回服务端 `403`，不能只依赖前端隐藏按钮。

## 数据与运行时

- 复用 `model_instance` 作为模型主记录。
- 复用模型 endpoint 表保存 Base URL、协议、权重和加密凭证。
- 复用模型 grant 表将模型授权给 `WORKSPACE`，系统模型使用系统范围授权。
- 运行时模型列表为“可用系统模型 + 当前工作空间已启用模型”的并集。
- 同一供应商和模型标识并存时，以模型实例 ID 区分，不做隐式覆盖。
- 已被任务显式选中的工作空间模型按实例 ID 执行，不静默回退到同名系统模型。

## API 行为

需要提供以下工作空间模型用例：

- 查询当前工作空间可用系统模型。
- 查询当前工作空间模型。
- 获取工作空间模型详情。
- 新增和更新工作空间模型。
- 启停工作空间模型。
- 测试未保存或已保存配置的连通性。
- 删除工作空间模型并返回依赖冲突。

所有接口统一返回可展示错误码，覆盖无权限、空间不存在、配置非法、凭证缺失、
连接超时、供应商拒绝和依赖冲突。

## 状态与异常体验

- 首次加载显示骨架屏，切换页签保留各自搜索条件。
- 空列表提供符合权限的操作指引。
- 请求失败保留已加载内容并提供重试，不用整页错误替换。
- 表单提交和连通性测试有独立 loading，防止重复提交。
- 空间切换后立即清理旧空间数据和表单，避免跨空间短暂泄漏。

## 验收标准

- 系统模型和工作空间模型在设置弹窗内可独立查询。
- Owner/Admin 能完成新增、测试、保存、编辑、启停和删除闭环。
- 普通成员的前端操作入口和后端写权限均受限。
- API Key 全链路不回显，日志和错误信息不包含密钥。
- 切换个人空间和团队空间后，模型列表严格随空间变化。
- 新增的工作空间模型能出现在任务模型选择器中并成功执行最小对话。
- 自动化测试覆盖合同、权限、脱敏、错误路径和运行时模型解析。
- 使用 Codex 内置浏览器验收弹窗布局、关键交互、网络结果和控制台错误。

## 非目标

- 不实现用户私有模型或用户私有 API Key。
- 不新增生态市场、模型交易、计费和额度结算。
- 不复制 Nuwax 的 Java 模型仓储或引入第二套模型运行时。
- 不允许普通成员共享、导出或读取工作空间模型凭证。
