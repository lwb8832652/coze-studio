# C 端菜单页面统一布局设计

## 背景

当前一级菜单页面已经共享 NewX 的颜色、圆角和按钮语义，但没有共享页面级
骨架。实测七个入口的标题横坐标相差 65px、纵坐标相差 88px，标题字号同时
存在 24px、26px、28px、30px 和 34px。部分页面有 52px 顶部状态栏，部分
页面直接从标题开始，造成明显的拼装感。

## 目标

- 让资源配置、网页应用开发、技能配置、开发配置、工作空间、任务中心和全部
  任务使用同一页面网格。
- 保留各页面的业务结构和核心交互，不把不同内容强行改成同一种列表。
- 保留 AppDev IDE、技能编辑器和任务详情的沉浸式工作台布局。
- 使用现有 NewX 令牌和 Coze Design 组件，不引入新的视觉体系。

## 统一页面骨架

所有一级菜单列表页采用以下合同：

- 页面背景：`--newx-color-bg-app`。
- 顶部状态栏：固定高度 52px，通知、专属助理入口和用户头像位置一致。
- 内容宽度：`min(calc(100% - 64px), 1180px)`，水平居中。
- 内容上边距：32px；页面底部留白：48px。
- 页面标题：28px、700 字重、36px 行高。
- 页面说明：14px、22px 行高，使用次级文字色。
- 标题区操作：固定在右上角，按钮高度 40px。
- 筛选区：标题区下方 20px，控件高度 40px。
- 内容区：白色面板、12px 圆角、统一边框和轻量阴影。

## 页面适配

- 资源配置：保留资源表格，补充页面说明并对齐筛选区。
- 网页应用开发：移除包裹整页的独立卡片感，标题、筛选、搜索和创建操作进入
  统一网格。
- 技能配置：保留技能卡片和创建方式，收敛 Hero 高度与字号。
- 开发配置：为共享列表布局增加稳定语义类，由统一骨架控制标题和筛选区。
- 工作空间：保留身份摘要和成员表格，摘要纳入统一内容宽度。
- 任务中心：保留统计卡片与任务表格，收敛 Hero、标题和最大宽度。
- 全部任务：保留任务筛选与列表，统一顶部状态栏后的内容起始位置。

## 响应式和可访问性

- 小于 900px 时水平内边距降为 16px，标题区操作允许换行。
- 顶部状态栏保留现有按钮语义、ARIA 标签、禁用态和键盘行为。
- 不通过 CSS 生成业务文字，不改变表格、筛选、弹窗和路由逻辑。
- 不改变 IDE 和任务详情的全屏工作台行为。

## 验收标准

- 七个一级菜单页面的标题左边界误差不超过 2px。
- 标题字号统一为 28px，标题区起始位置一致。
- 页面不存在横向溢出，900px 以下可正常换行。
- 顶部状态栏、主操作、筛选区和内容面板顺序一致。
- 现有创建、搜索、筛选、分页和页面跳转功能保持可用。
