# Nuwax 生态 MCP 目录迁移设计

## 目标

将 Nuwax 本地生态市场 `/ecosystem/mcp` 当前可见的 24 个 MCP 条目完整纳入
Coze 现有“设置 > MCP 配置 > 官方服务”，不新增一级菜单，也不复制 Nuwax
私有凭据或伪造不可运行的部署配置。

## 产品合同

- 官方目录由平台维护，工作空间只保存安装实例和工作空间级凭据。
- 目录展示名称、说明、图标、发布方和来源，支持按名称、说明和发布方搜索。
- `installable` 表示已有经过核实、可独立部署的公开运行模板。
- `adapter_required` 表示目录信息已迁移，但运行依赖 Nuwax 私有网关或缺少公
  开部署模板；页面展示原因并禁止安装。
- 安装限制同时由前端和后端执行，不能通过直接调用 API 绕过。
- 已有 GitHub、PostgreSQL 官方条目保持兼容。

## 可直接安装范围

已核实公开运行模板的 5 个 Nuwax MCP：

- Fetch 网页内容抓取
- 今日热点
- 12306 车票查询
- Time
- 学术文章搜索服务

“今日热点”要求工作空间提供 NewsNow 服务地址。地址仅允许有效的 HTTP 或
HTTPS URL。

## 需要平台适配范围

图像服务、PDF 内容提取、联网搜索和数据导出服务依赖 Nuwax 私有 SSE 网关。
其余没有公开独立部署模板的条目也保留在目录，但在 Provider 适配完成前不
允许安装。这样既保证目录完整，又不制造“按钮可点但运行失败”的假闭环。

## 验收要点

- 官方服务总数为 26：Coze 原有 2 个加 Nuwax 24 个。
- 24 个 Nuwax 条目的名称、说明、图标和“女娲官方”发布方可见。
- 5 个公开模板可以进入安装流程；其余条目显示平台适配原因且不可安装。
- 搜索覆盖名称、说明和发布方。
- 后端拒绝安装 `adapter_required` 条目。
- 已有 GitHub、PostgreSQL 安装和迁移行为不回归。
